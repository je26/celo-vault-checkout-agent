How it fits together: the agent wallet is delegated to Porto for the Altana session. A delegated wallet cannot sign EIP-3009 (USDC checks ERC-1271, which the delegation fails), so the session key — a plain EOA holding its own USDC, funded from the wallet through the session — signs the x402 payments. Session and payments both live on mainnet.
