How Agent Vault is integrated

Agent Vault has no API key and no embeddable widget. The integration is its MCP server (mcp.agentvault.io/mcp) over streamable HTTP with OAuth. The agent connects as an MCP client, drives a browser inside the Agent Vault proxy, and fills sign-in and checkout fields with mock tokens. The proxy swaps each token for the real value at the moment of the fill. The agent never sees the password or the card number.
Proven 2026-11-23 ~19:56 WIB: open figma.com/login, fill_login filled 2/2 fields with the saved login tokens, submit, then the Figma home ("Drafts") loaded and the login form was gone (email and password fields count 0). The login is saved by the owner in the Agent Vault dashboard. Connection scope: 1 card, 1 login. Docs: docs.agentvault.io.
